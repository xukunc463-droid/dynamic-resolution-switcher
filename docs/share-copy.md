# Sharing copy

## V2EX / Chinese communities

标题：开源了一个免安装的 Windows 分辨率和刷新率快速切换工具

每次进游戏前都要进显卡控制面板改分辨率、刷新率，我就做了一个小工具。它不创建自定义分辨率，而是直接列出 Windows 和驱动已经提供的主显示器模式，双击就能切换。单 EXE、免安装、不联网。

我在自己的《无畏契约》环境中，配合 NVIDIA 缩放、游戏内设置和已创建的自定义分辨率，观察到了真实拉伸；工具本身只切 Windows 模式，不会改显卡缩放或游戏设置。

下载和源码： https://github.com/xukunc463-droid/dynamic-resolution-switcher

## Reddit

Title: I made a portable Windows resolution and refresh-rate switcher

I got tired of opening the GPU control panel before games just to change resolution or refresh rate, so I made a small open-source utility. It lists modes already exposed by Windows and the driver for the primary display, then switches them with a double-click. Single EXE, no install, no admin, no network.

Source and downloads: https://github.com/xukunc463-droid/dynamic-resolution-switcher
